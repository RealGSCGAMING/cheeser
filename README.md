# Welcome to Cheeser Inc!
I presented this website on the final day of my AP Computer Science A class. I designed everything except the Checkout page, which was designed using AI.

Some of the homepage design was inspired by the opening of Link Click. As I tried to replicate the sliding text effect, I learned that cool animations are significantly easier to make in a TV animation than in CSS.

This project also serves as the landing page for my website, https://cheeserinc.com.
